# Township Task Helper

Township tasks take a lot of planning. Which ore, how many bars, which arrows, which monster, what level. Township Task Helper does the planning for you, then does the grinding too.

## One click, full plan

Every task in your Township list gets a green play button. Press it and you see the steps in order for exactly what you still need. Already have the logs? That step is skipped. Not high enough level? You find out right away, before you spend an hour on it. Short on feathers? Buy them from the same window.

## Walk into fights ready

Monster tasks show how the enemy attacks, what it's weak to and where to find it. You can check your food and swap equipment sets without closing the window.

## Let it run

Add a plan to the Action Queue and walk away. It gathers, crafts, trains and fights, one step after another, and pauses with a note if something needs you. Start it before bed and wake up to finished tasks.

## Small things that save time

- It picks the best XP method you can actually use
- Extras it makes along the way get sold for you
- It won't queue the same step twice
- If it can't find where an item comes from, it points you to the wiki
- Turn on auto-start and the queue begins as soon as you add something

## Install

Subscribe on mod.io from the in-game Mod Manager (Browse tab): https://mod.io/g/melvoridle/m/action-queue

To try it from source, zip `manifest.json` and `setup.mjs` (both at the top level of the zip) and load it as a local mod with the Melvor Creator Toolkit.
